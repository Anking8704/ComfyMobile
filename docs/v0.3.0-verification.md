# 0.3.0 验证记录

用户反馈：界面不是全屏，功能键应可隐藏；提示词节点要双击才进入提示词界面。并要求适配大部分手机屏幕，另做 iPad 可用版本。

## 实现

- **全屏画布**：工作流页不再有 APP 头栏、进度行、工具行和底部导航。Android 11+ 用 `WindowInsetsController` 隐藏系统栏（边缘滑动临时呼出），Android 10 用沉浸式 sticky 标志；只在画布页启用，提示词页恢复系统栏，不使用全局 `FLAG_FULLSCREEN`，原生输入法的 adjustResize 不受影响。刘海/挖孔屏使用 `SHORT_EDGES` 并由根视图安全区内边距处理。
- **原版菜单**：通过前端自带的 `extensionManager.focusMode`（适配脚本 `chrome` 命令）隐藏原版侧栏、顶部栏和运行栏，每次页面载入后按用户设置重新应用；圆形菜单“原版菜单”可随时切换，原版右上角汉堡按钮仍能恢复。
- **可隐藏功能键**：新增 `FloatingMenu`。收起时只有一个半透明圆形按钮，可拖到左右边缘并记住位置；展开为底部面板，含全部原有功能（生成、提示词、节点、添加、适应画布、任务、图库、横/竖屏、原版菜单、连接设置、更多）。返回键先收起面板。采样进度以画布顶部小标签显示，5 秒无更新自动隐藏。
- **双击进入提示词**：适配脚本改为真实指针状态机。单击文字框只设置 `inputmode=none` 并释放网页焦点，不跳页、不弹网页键盘；两次点击需落在同一字段、间隔 450 ms 内、位移 40 px 内，期间拖动超过 14 px、第二根手指或 pointercancel 都会取消。双击节点主体（不含标题栏、不含其他画布控件）时，若节点只有一个文字字段则直接打开，多个则发出 `pick_field` 让用户选择，不猜正/反向。键盘 Tab/Enter 进入字段视为明确编辑请求。字段身份校验、草稿保护逻辑未改。
- **屏幕适配**：按钮单行并按宽度/系统字号自动缩小（10–15sp）；对话框列表高度限制为屏幕高度一半；平板连接页居中限宽；任务与图库按屏幕宽度 1–4 列；菜单面板按宽度 3–6 列、最宽 560dp。
- **iPad 网页版**：`web/comfymobile_web` 为 ComfyUI 自定义节点，只注册 `/comfymobile/` 静态页面（白名单文件，拒绝路径穿越）。页面以同源 iframe 嵌入原版编辑器并注入同一份 `editor-adapter.js`，提供圆形菜单、双击编辑、提示词页（横屏宽屏时词库常驻右侧）、中英词库与收藏、任务、图库、导入/导出。支持“添加到主屏幕”全屏运行。`scripts/install-web.ps1` 负责复制到 `ComfyUI\custom_nodes\ComfyMobileWeb`。

## 自动验证

- `scripts/build.ps1`：8 组 Java 主机测试与 33 项 Node 测试通过（新增：单击不跳页、双击打开准确字段、拖动/远距离/跨字段/多指不误触、首次点击引起的 focus 只释放不跳页、键盘 Tab 交接、节点主体双击单字段/多字段、focus mode 命令）。
- APK 编译、对齐、签名通过；`local.comfymobile`，versionCode 3，versionName 0.3.0；签名证书 SHA-256 与 0.2.0 相同（`ac390b55…d806f2`），可覆盖安装。
- `scripts/smoke-mobile-input.cjs`（本机 8188 只读代理 + Edge 无头，915×412，CDP 真实触摸事件）：focus mode 后画布等于视口；真实单击不跳页且网页文字框未保持焦点；真实双击打开准确节点/字段；双击节点主体打开唯一字段；写回、搜索框不受影响、原版菜单可恢复。结果：`docs/v0.3.0-input-handoff-result.json`。
- `scripts/smoke-web.cjs`（同一只读代理）：iPad 横屏 1180×820、iPad 竖屏 820×1180、手机 375×667 三种尺寸下，适配脚本注入、原版菜单隐藏且画布全屏、单击不跳页、真实双击打开准确字段、词库只插入英文、保存写回节点、菜单面板在屏幕内、图库页无横向溢出。结果：`docs/v0.3.0-web-result.json`。测试中发现并修复了手机尺寸下“松手打开菜单后同一次点击落到新出现按钮上”的幽灵点击问题。
- 网页版路由在 aiohttp 中单独验证：`/comfymobile` 302 跳转，页面与脚本 200，`..%2F__init__.py` 与非白名单文件 404。

## 独立审阅

由独立审阅代理只读检查全部改动，确认字段身份校验、草稿保护、收藏按内容定位、只插入英文、生成不重试均未回退，网页版路由无路径穿越、innerHTML 均已转义。据审阅修复：

- Android 10 沉浸模式下  使隐藏后的系统栏仍占内边距：去掉该标志。
- Android 10 横屏挖孔区未计入内边距：取系统栏与 DisplayCutout 安全区的较大值。
- 旋转、深色模式切换会重建任务/图库并退出正在查看的任务图片：只在列数变化且未查看单个任务时重建。
- 画布绘制的单行文字控件首次单击会弹出原版输入框：改为由适配脚本直接认领，单击无动作、双击进入原生编辑。
- 指针抬起丢失后下一次点击被吞：过期的点击状态直接丢弃。
- 已被连线驱动的文字输入不再从节点主体双击中提供编辑。
- 网页版：桥接调用 45 秒超时，避免“开始生成”永久禁用；新对话框会关闭并结算旧对话框；适配脚本每次页面载入只注入一次。

## 未验证范围

- 仍没有安卓真机或模拟器：沉浸式系统栏、圆形按钮拖动、原生输入法、Android 10 的系统 UI 标志只经过编译，未在设备上运行。
- 没有真实 iPad：Safari/WebKit 的触摸、`inputmode=none`、添加到主屏幕全屏、键盘遮挡处理只在 Chromium 内核的 Edge 移动模拟中验证。
- 网页版自定义节点已复制到 `ComfyUI\custom_nodes\ComfyMobileWeb`，但正在运行的 ComfyUI 没有重启，`/comfymobile/` 需重启后才在 8188 上生效。
