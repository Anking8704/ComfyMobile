# 验证记录

日期：2026-10-27。此记录区分自动验证与尚需安卓设备验证的行为。

## 已执行

- 6 组 JDK 主机端测试：服务器地址规范化、同来源 URL 检查、真实本地 HTTP 服务的重定向/错误/传输限制、Unicode 图片路径编码、图片文件名处理、提示词选区权重、草稿恢复与写回状态、提交取消及旧回调隔离。
- 16 项 Node JavaScript 适配测试：标准自定义字符串字段读写和回调、下拉选项不进入提示词选择列表、工作流/节点/控件更换、页面重载令牌冲突、工作流加载序号变化、错误 JSON 导入、工作流导出再导入、导入失败恢复原工作流、重复提交拦截、前端校验拒绝、吞掉网络错误时不能误报成功、进度事件读取。
- Android SDK 35 资源链接、Java 编译、DEX 转换、APK 对齐、开发签名和 apksigner 校验。
- aapt 包信息检查：包名 local.comfymobile，最低 Android 10（API 29），目标 API 35；权限仅 INTERNET 和 ACCESS_NETWORK_STATE。
- 对照本机已安装 comfyui-frontend-package 1.55.18 的兼容入口和前端代码，确认 app、LiteGraph、graphLoadSequence、queuePrompt 返回值、预览事件名称等接口。
- ADB 设备清单检查：无已连接设备。因此没有宣称安装、触屏、输入法、相册保存或实际生成通过真机测试。
- Windows PowerShell 5 与 PowerShell 7 均运行过自动测试；最终 APK 由 Windows PowerShell 5 脚本构建。编译有旧 Java 选项和平台 API 弃用提示，无编译错误。
- 独立代码审阅的必要修复和保留的小问题见 `review.md`。
- 真实前端集成：使用本机 ComfyUI 0.42.1 与前端 1.55.18，在临时用户目录、仅回环端口 8199、CPU/offline 模式运行，再用 Edge 无头浏览器的 412×915 视口检查。读取 683 种内置类型；白名单启用已安装的 comfyui-anima-enhancer 后读取 684 种类型。实际创建 CLIPTextEncode、EmptyLatentImage、KSampler、AnimaLayerReplayPatcher，写回中文提示词和自定义 block_indices 字段，建立 latent 连线，导出再导入并验证字段保留和旧目标写回拒绝。这个数字是测试配置中的类型数，不是完整安装的全部节点总数。
- 集成测试只验证浏览器和工作流接口，不提交生成请求，不加载模型；测试结束后关闭临时服务和浏览器。原有 ComfyUI 工作区的模型占位文件删除状态保持原样。

## 安装后验收

1. 手机同 Wi-Fi 连接电脑，打开既有工作流。
2. 添加、移动、连接、断开、复制和删除标准节点；修改参数后导出再导入检查保留情况。
3. 选择实际正向/反向文字字段，测试拼音选字、换行、粘贴、语音输入法、选择权重、撤销重做、常用词和旋转；确认保存按钮位于键盘上方。
4. 关闭并重开应用，确认草稿仍在；重新绑定字段。切换工作流后旧目标保存必须失败，草稿应保留。
5. 运行一个电脑上已经能生成的工作流，查看进度、结果、原图保存及系统分享；测试中文文件名、子目录和多张输出。
6. 断开 Wi-Fi 后恢复，确认没有自动重复提交。
7. 对实际常用第三方节点逐项检查，尤其是姿态、蒙版和其他特殊前端控件；尚未建立真机插件兼容清单。

## 未验证

无真机/模拟器运行记录，无电脑 GPU 实际生成记录，无所有第三方插件兼容保证。一个真实自定义节点的浏览器字段往返检查，不能替代姿态/蒙版/3D 等特殊插件在手机上的操作验证。
