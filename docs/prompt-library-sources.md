# 内置英文提示词库：来源与适用范围

核对日期：2026-10-27。数据文件：`app/src/main/assets/prompt-library.json`，版本 1。

本库包含 **24 个分类、384 个英文词条、30 个英文场景模板**。词条的中文名称和中英文关键词用于查找；每个词条和模板均有独立的中文 `translation`，供界面展示中英对照，模板译文完整翻译场景。点击词条或模板时仅将英文 `text` 插入提示框，不应把中文翻译一起插入。模板的 `note` 是中文使用说明，也不应拼进生成提示词。分类覆盖人物、面部、发型、发色、表情、姿势、活动、服装、服装细节、配饰、构图、镜头、光线、配色、风格、媒介、自然场景、建筑、室内、天气时间、动植物、幻想、静物和材质。

## 如何使用

1. 先挑主体、动作、场景和光线，每次只增加少量概念。英文词条是可选积木，不必把整类内容一起加入。互斥描述应择一，例如长发与短发、写实摄影与纸雕。
2. 标签型动漫模型可尝试以逗号分隔短语。标签识别来自训练数据：本库不是任何一个模型的完整、精确标签表，也不能保证每个英文短语都是其规范标签。
3. SDXL 的效果取决于基础模型、微调、文本编码器与节点实现。模板可作为普通英文起点，但动漫 SDXL 和写实 SDXL 的偏好不同，不能一套标签通用。
4. Anima 的官方模型卡支持标签、自然语言及混用；标签通常使用小写和空格。模板采用完整自然语言，人物明确为成年人，内容为一般人像、服装、活动和环境。写实模板的说明会提醒改成插画。Anima Base、Aesthetic、Turbo 的设置与提示偏好不同，应以正在使用版本的模型卡为准。
5. 更偏自然语言的模型宜描述清楚谁在何处做什么，以及主体之间的位置关系。不要仅凭界面能够输入，就推定模型支持 `(word:1.2)`、大括号强调或其他特殊语法。
6. 内置模板默认不附带负面提示词，也不附带质量词、评分词或固定权重。需要负面提示时，先确认工作流支持负面条件，再针对实际出现的问题加少量词。负面词并非所有模型或引导设置都有效，也不保证修复手、文字或构图。
7. `masterpiece`、`best quality`、`score_*` 等词是否有意义取决于训练标注及模型版本。本库不把这些词或分辨率词视为万能增益。Anima 官方对 Aesthetic 版特别说明无需质量词，并建议避免正负提示中的评分标签；不要把 Base 的建议机械套用到其他版本。
8. 生成图片的精确文字、手部、乐器握持、自行车结构、多人物对应关系与复杂空间关系仍需检查。模板中的摄影、镜头、材质是意图描述，不是强制渲染或相机参数。本次完成的是数据与资料校验，没有运行模型逐项评估图像效果。

## 数据约定与校验

`categories[].id` 唯一；`label` 和 `keywords` 提供中文检索；所有词条和模板的 `text` 均为可读 ASCII 英文。每项独立的 `translation` 为中文释义：词条可与准确的中文 `label` 相同，模板则是与原文主体、活动、环境一致的完整译文，不以名称或模型说明替代。词条在忽略大小写、空格、连字符及下划线差异后全局去重。每个模板的 `category` 指向实际分类，`note` 提供适用说明；需要时可用可选 `negative` 字段存放英文负面提示，本版本未预置。

运行 `node --test tests/prompt-library.test.cjs` 可检查分类与数量下限、词条全局去重、必填字段、中文检索信息、英文内容、模板长度与分类引用，以及原始资料链接是否随库提供。翻译检查覆盖全部 384 个词条与 30 个模板，要求中文译文非空、模板至少 35 个中文字符，且保持英文插入文本独立；译文忠实度由逐项人工语义核对保证，长度检查本身不证明翻译准确。该测试不验证图片质量，也不代替模型兼容性实测。
