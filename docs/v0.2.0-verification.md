# 0.2.0 验证记录

用户反馈：竖屏画布太小；节点自带文字框唤起输入法后无法继续输入。用户指定交互为点击节点文字框跳转原生提示词页，并要求内置英文提示词、扩充词库以及中文翻译。

## 实现与证据

- 提供显式横/竖屏按钮及系统方向恢复入口。通过 Manifest 配置变化处理保留 Activity、WebView 和 EditText 对象；旋转时不调用页面重建或键盘隐藏逻辑。横屏工作流将工具和生成合为一行，隐藏多余栏。
- 移除提示词页依赖键盘压缩高度切换控件可见性的布局监听，改成固定的顶部字段栏、弹性原生文字区和单行底部工具。键盘出现时不重新生成 EditText、改写文字或清空焦点。
- 已知 ComfyUI 标准文字控件的 pointerdown 在网页输入法开启前交给原生编辑页；仅近期用户操作后的 focusin 可回退交接，避免前端启动时程序性 focus 导致自动跳页。搜索框和下拉选项不交接。目标使用原有工作流/节点/控件身份令牌，交接前再次校验，保存仍拒绝陈旧字段。
- 原生编辑页显示期间不轮询隐藏 WebView；窗口重新获得焦点后再请求系统 IME，不使用 SHOW_FORCED。根视图已处理的窗口 inset 归零后向子视图分发，避免错误保留旧 WebView inset。
- 词库包含 24 类、384 词条、30 个模板。英文 text 与中文 translation 分开；中文标签和完整模板译文用于检索/显示，点击只应用英文。保留自写收藏，仅替换旧版精确匹配的内置默认值。
- 版本号 0.2.0、versionCode 2，使用既有签名密钥，可覆盖安装 0.1.0。

## 自动检查

8 组 Java 主机测试覆盖连接策略、传输、文字权重和选区插入、草稿状态、提交状态、旧默认词迁移和收藏并发变更保留。24 项 Node 测试覆盖字段交接、搜索框排除、启动焦点排除、精确写回，以及词库数量、全局去重、英文内容和中文翻译完整性。

独立审阅发现词库窗口的旧快照可能覆盖同窗口刚新增的收藏，已改为保存/删除时重新读取最新列表并按原条目内容定位，PresetListTest 覆盖新增后编辑/删除、原条目已变更与不修改原列表。焦点回退单测也已使用真实 focusin 事件类型，并断言网页输入框 blur 与事件去重。

`scripts/smoke-mobile-input.cjs` 使用真实本机前端、915×412 浏览器视口及只读代理：不转发生成、保存或任何非 GET 请求，不修改用户工作流。验证实际 CLIPTextEncode DOM 文本框的 pointer 拦截、正确字段交接、英文写回、普通搜索框排除和 focus 回退。它不是安卓输入法测试。

## 仍须手机验收

当前没有 ADB 连接的安卓设备，本机不具备可用的模拟器加速条件。尚未验证具体手机输入法的组合输入、键盘动画和 OEM 方向行为。请覆盖安装后测试：点节点文字框自动进入提示词页、连续输入中文和英文、选词与换行；横竖屏切换不丢草稿；中英文检索、中文译文显示、英文插入和写回节点。特殊插件编辑器仍需逐项实际验证。
