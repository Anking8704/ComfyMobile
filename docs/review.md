# 独立审阅与实现决定

2026-10-27，一位独立审阅代理对首个实现提交进行了只读审阅。5 项 Important 均进入修复；无已确认的 Critical。

## 已处理的必要问题

1. 恢复的手机草稿不能被重新选择字段静默覆盖。增加 DraftState 与主机测试，提供“保留草稿并绑定”与“载入节点文字”两个明确操作，并显示上次目标信息。
2. 键盘和横屏可用高度变小时，提示词页隐藏 Activity 头栏并折叠工具区域，保留文字区、紧凑工具和保存按钮；这项布局已编译，仍需安卓真机验证。
3. 本机真实前端可能吞掉网络异常并从 queuePrompt 返回 true。改为关联本次 promptQueueing/promptQueued 的 requestId，收到接受事件才报成功；未确认时提示检查任务，不自动重试。回归测试覆盖吞异常返回 true 的实际接口行为。
4. loadGraphData 返回 false 不能视为成功。增加失败检测与回归测试，导入失败时尝试恢复原画布；原生层先将导入前工作流保存为手机私有文件，“更多”可导出该备份。
5. 切换服务器取消本地提交状态，SubmissionState 用请求世代拒绝旧回调；新增主机测试。提交期间切换标签后，完成回调也会恢复当前生成按钮。

额外验证发现 Windows PowerShell 5 不能正确解析无 BOM 的中文脚本，已改为 UTF-8 BOM 并用 Windows PowerShell 重新执行测试与构建。

## 保留的小问题

任务页的列表缓存仅比较生成历史。历史不变而运行队列变化时，顶部运行数量会更新，但具体运行条目可能需要点“刷新”才显示。这不影响任务执行、生成历史或原图保存。

## 实现方做出的决定

- 新建独立同级项目作为隔离工作区，保留现有 ComfyUI 仓库和模型状态；不创建或合并 ComfyUI 分支。
- 用户已明确要求开始，按批准范围在当前会话执行，不再增加计划确认轮次。
- 使用官方 Android 工具直接构建，省去 Gradle 与第三方安卓依赖；代价是源码需按提供的脚本构建。
- 用户要求的手机收图，首版定义为前台显示结果、手动保存原图；后台常驻和锁屏自动下载不在首版保证内。
- 保留第三方节点原编辑器入口。自动测试中的自定义字符串控件不是所有真实插件的兼容证明；姿态/蒙版/3D 等特殊控件需实测。
- 无已连接安卓设备，不能验证真实输入法、系统相册与分享授权、WebView 设备差异和 GPU 生成。因此交付标为可安装的本地开发版，不称为已通过真机验收。
