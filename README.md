# ComfyMobile 0.3.0

连接家中电脑 ComfyUI 的安卓客户端，另附 iPad / 平板网页版。电脑运行现有模型和节点，手机编辑工作流、输入提示词、查看任务和保存原图。Android 10 或以上，需要更新的系统 Android WebView。

这是可安装的本地开发版本，已构建并通过签名和主机端逻辑验证；尚未在安卓真机或模拟器完成端到端测试。设计参考图不是 APP 实测截图。第三方节点的特殊前端界面需要实际工作流验证，不能保证所有插件都已适配触屏。

## 安装与连接

1. 把 `output/ComfyMobile-0.3.0.apk` 传到手机，点开安装。已装 0.1.0 / 0.2.0 的手机直接覆盖安装，使用同一签名，不需要卸载；草稿和收藏可保留。系统要求时允许本次使用的文件管理器安装应用。
2. 手机和电脑连接同一个 Wi-Fi，电脑保持开机。
3. 在绘世启动器打开“高级选项 → 监听设置”，开启“开放远程连接”，端口保留 `8188`；也可在启动参数中加入 `--listen 0.0.0.0 --port 8188`。修改后需要重启 ComfyUI 才生效，保留原来的显卡、性能等参数。
4. 用手机浏览器先打开 `http://电脑局域网IP:8188`。能看到 ComfyUI 后，在 APP 的“连接设置”填相同地址并点“检测并连接”。APP 会记住地址。

本次检测到的电脑 Wi-Fi 地址是 `192.0.2.10`，因此当前可用地址为 `http://192.0.2.10:8188`，以电脑实际监听端口为准。该地址可能在重新联网后改变。

双击 `检查局域网连接.cmd` 会检查本机状态并显示连接地址，不会启动第二个 ComfyUI 实例。推荐从绘世启动器启动；也可用下面的脚本启动整合包中的 Python，关闭该终端会结束该次运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-comfy-lan.ps1
```

也可以双击 `启动ComfyUI局域网.cmd` 执行上述启动脚本。

打不开时，确认没有连接访客 Wi-Fi、路由器未隔离设备，且 Windows 防火墙允许家庭网络访问对应 Python/ComfyUI。APP 不自动修改防火墙或路由器。

如果 APP 报 `failed to connect ... after 8000ms`，先检查电脑是否只监听 `127.0.0.1:8188`。电脑浏览器可以打开 `127.0.0.1`，不能证明手机可以连接；需按上面的步骤开启“开放远程连接”并重启，再用手机访问电脑局域网地址。仅修改启动器开关而未重启，不会改变正在运行的进程。

## iPad / 平板网页版

iPad 无法安装 APK，因此提供同一套功能的网页版，作为 ComfyUI 自定义节点运行在电脑上（只增加一个网页地址，不注册节点、不改模型和原版前端文件）。

1. 在电脑执行一次安装（复制到 `ComfyUI\custom_nodes\ComfyMobileWeb`）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-web.ps1
```

2. 重启 ComfyUI（需已开启“开放远程连接”）。
3. iPad 用 Safari 打开 `http://电脑局域网IP:8188/comfymobile/`，例如 `http://192.0.2.10:8188/comfymobile/`。
4. 点 Safari 的“分享 → 添加到主屏幕”，之后从主屏幕图标打开即为全屏，无地址栏。

网页版与安卓版共用同一份编辑器适配脚本和双语词库：全屏画布、可拖动的圆形菜单按钮、双击提示词节点进入编辑、中英对照词库与收藏、任务与图库。横屏时词库常驻在编辑区右侧。收藏和草稿保存在该 iPad 的 Safari 中。图库中点“查看原图”后长按图片可“存储到照片”。也可用于其他平板或手机浏览器。更新 APP 源码后重新执行安装脚本即可同步网页版。

## 使用

- **全屏画布**：工作流页隐藏系统状态栏、导航栏、APP 头栏和原版 ComfyUI 菜单，整屏都是画布。从屏幕边缘滑动可临时呼出系统栏。屏幕上的圆形按钮展开全部功能（生成、提示词、节点、添加、适应画布、任务、图库、横/竖屏、原版菜单、连接设置、更多），点“收起”或返回键收回；按住圆形按钮可拖到左右任意边，位置会记住。需要原版菜单时点“原版菜单”切换，设置会记住。生成时画布顶部显示采样进度。
- **横屏**：圆形菜单和提示词页都有横/竖屏切换；“更多”里可恢复跟随系统。旋转不重新载入工作流或重建提示词框。
- **工作流**：加载电脑提供的原版完整编辑器。“节点”打开列表，可定位、修改参数、复制、删除，或选择输出端口和目标输入端口连线。“添加”搜索电脑已安装的节点。“适应”调整画布视野。
- **提示词**：**双击**节点自带的标准文字框（或双击只有一个文字框的提示词节点主体），跳到原生全屏提示词页；单击只用于选择和拖动，不会弹出网页输入法。节点有多个文字框（如正/反向在同一节点）时会让你选择字段，不会猜测。进入后绑定实际字段并请求弹出系统输入法。“保存到节点”写回该字段；回车只换行，不会生成。也可点提示词页顶部字段名或“工具 → 选择节点字段”手动选择。正向、反向或其他文本以实际字段为准，不自动猜测。无法识别的插件专用编辑器保留原来的操作方式。
- **中英对照词库**：内置 24 类、384 个英文词条、30 个完整英文模板，均有中文翻译。支持中英文搜索与分类筛选；长按可看完整中英对照和适用说明。点击应用只插入英文，不插入中文译文。模板在“工具 → 英文模板”打开。词库来源与模型差异见 `docs/prompt-library-sources.md`，所有内容离线随 APK 提供。
- **收藏 / 模板 / 历史**：词条插入光标或替换选区，模板和历史可替换草稿；按“分类 / 内容”保存个人收藏，长按可编辑或删除。只迁移旧版少数自带中文默认词，不翻译或清空用户自写内容。权重、撤销、重做和历史在提示词页“工具”中。
- **任务**：查看运行中、等待和最近完成的记录。断线或重新打开后从电脑恢复记录，不自动重新提交。
- **图库**：自动刷新前台生成结果，查看图片，点“保存原图”写入相册 `Pictures/ComfyMobile`；“分享”会先保存原图再打开系统分享。
- **更多**：导入或导出工作流 JSON，撤销，查看最近一次实时预览。预览需要电脑启用预览且前端实际收到对应事件。图片上传和插件专用功能继续使用完整编辑器中的控件。

草稿、常用词和模板只存在这台手机。工作流需使用编辑器的保存功能，或在“更多”导出 JSON；手机草稿不等于工作流保存。切换工作流、重新加载页面或删除目标节点后，需重新选择提示词字段。

## 范围与当前限制

- 完整画布由系统 WebView 加载电脑现有前端。标准节点及自定义节点仍在电脑执行；手机端不安装模型，也不提供新的推理引擎。
- 原生参数面板处理标准文字、数值、开关和选择控件。特殊姿态编辑、蒙版、3D 或自定义绘图控件使用插件原界面，触屏兼容性尚待真机验证。
- 前台每 4 秒刷新任务与图库。应用退出、锁屏或被系统回收后，不保证后台收图或常驻通知。
- 图库显示最近 30 个任务中最多 40 张图片。原图相册保存单张上限 150 MiB，大于此值可在完整编辑器下载。图片预览为缩放显示，保存原图不会重新编码。
- 服务器地址支持根路径 HTTP(S)，不支持带路径前缀的反向代理。首版以家庭局域网、无额外认证的本机 ComfyUI 为目标。
- 本地开发签名保存在 `.tools/comfymobile-dev.keystore`。请保留该文件，后续升级需要同一签名。它不是商店发布签名。
- 适配不同屏幕：按钮文字随宽度和系统字号自动缩小，对话框列表高度随屏幕调整，平板和横屏下表单居中、任务与图库多列显示，刘海/挖孔屏由系统安全区处理。
- 当前任务页在历史记录不变时，运行数量会更新，但具体运行条目有时需要手动点“刷新”。详见 `docs/review.md`。

## 构建与测试（Windows）

不依赖 Gradle、Android Studio 或第三方安卓运行库。首次准备工具需要联网，下载 Microsoft OpenJDK 与官方 Android SDK；工具只放在项目 `.tools`，不会改系统 PATH。建议至少预留 2 GB 空间。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup-tools.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

脚本使用 Node.js 执行 JavaScript 适配测试，需先安装 Node.js。开发电脑本次使用 Node 24，JDK 21，Android SDK 35，Build Tools 35.0.0。

真实前端检查（只读代理，不提交生成、不改电脑上的工作流）：

```powershell
node .\scripts\smoke-mobile-input.cjs
node .\scripts\smoke-web.cjs
```

只运行自动测试：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1 -TestOnly
```

输出为 `output/ComfyMobile-0.3.0.apk`。本版测试和构建记录见 `docs/v0.3.0-verification.md`，上一版见 `docs/v0.2.0-verification.md`，初版记录见 `docs/verification.md`，设计和实施计划见 `docs/superpowers/`。
