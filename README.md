# ComfyMobile 0.4.4

连接家中电脑 ComfyUI 的安卓客户端，另附 iPad / 平板网页版。电脑运行现有模型和节点，手机或 iPad 编辑工作流、输入提示词、出图、查看任务和保存原图。安卓需 Android 10 或以上，以及较新的系统 Android WebView。

这是可安装的本地开发版本，已构建、签名，并在电脑上用真实 ComfyUI 前端做了自动化检查；**尚未在安卓真机、模拟器或真实 iPad 上完成端到端测试**。第三方节点的特殊界面需要实际工作流验证。

## 安装与连接（安卓）

1. 把 `output/ComfyMobile-0.4.4.apk` 传到手机安装；或者电脑装好网页版后，用手机浏览器打开 `http://电脑地址:8188/comfymobile/`，在“更多”里下载安卓安装包。已装旧版直接覆盖安装，签名相同，草稿和收藏保留。
2. 手机和电脑连接同一个 Wi-Fi，电脑保持开机。
3. 在绘世启动器打开“高级选项 → 监听设置”，开启“开放远程连接”，端口保留 `8188`（或启动参数 `--listen 0.0.0.0 --port 8188`），修改后重启 ComfyUI。
4. 打开 APP：点“自动查找局域网中的电脑”，或手动填写地址（例如 `http://192.0.2.10:8188`）后点“检测并连接”。最近连接过的电脑会列在上方，点一下即可切换。手机在用流量时，APP 会直接提示先连 Wi-Fi。

建议在路由器里给电脑设定固定 IP，地址就不会变化。在外面使用：电脑和手机都安装 Tailscale 或 ZeroTier 等组网工具后，填电脑的组网地址即可，不需要公网服务器。

双击 `检查局域网连接.cmd` 可检查本机状态。打不开时，确认没有连访客 Wi-Fi、路由器未隔离设备，且 Windows 防火墙允许对应 Python。

## iPad / 平板网页版

iPad 无法安装 APK，因此网页版作为 ComfyUI 自定义节点运行在电脑上（只增加一个网页地址，不注册节点、不改模型和原版前端文件）。

1. 在电脑执行一次安装（复制到 `ComfyUI\custom_nodes\ComfyMobileWeb`）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-web.ps1
```

2. **完全重启 ComfyUI 一次**（在启动器里停止再启动，或关掉控制台窗口后重新启动；刷新网页不算）。之后更新网页文件不再需要重启。
3. iPad 用 Safari 打开 `http://电脑局域网IP:8188/comfymobile/`，点“分享 → 添加到主屏幕”，以后从主屏幕图标打开即为全屏。

注意：iOS 上“添加到主屏幕”的图标和 Safari 各自保存登录信息，在 Safari 里输过的访问口令、AI 助手配对，在主屏幕版里需要再做一次。

网页版与安卓版功能一致：全屏画布、圆形菜单、双击编辑、简洁模式、工作流保存/打开、中英词库（横屏时常驻右侧）、任务与图库。收藏与 APP 通过电脑同步。看原图时可双指放大，长按图片可“存储到照片”。网页无法使用屏幕常亮和后台通知（Safari 只在 HTTPS 下开放这些功能）。

**可选：局域网访问口令。** 同一网络里有不信任的人（宿舍、公司）时可开启，本机浏览器不受影响：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-web.ps1 -Token 你的口令
```

开启后 iPad 打开一次 `http://电脑地址:8188/comfymobile/login?token=你的口令` 即可；安卓 APP 在连接页填写“访问口令”。用 `-Token ''` 关闭。

## 使用

- **全屏画布**：工作流页隐藏系统栏、APP 栏和原版菜单，边缘滑动可临时呼出系统栏。圆形按钮展开全部功能，可拖到左右任意边；点画布或返回键收起。原版的“选中节点工具条”默认隐藏，因为在手机上它会挡住第二次点击，可在“更多”中打开。
- **简洁模式（出图模式）**：工作流做好后，点“简洁模式”切换。只显示关键参数：正向/反向提示词、种子（含随机、生成后种子方式）、步数、CFG、采样器、尺寸（含常用尺寸一键设置）、所有模型加载器（大模型、UNET/GGUF、CLIP 模型和类型、VAE、每个 LoRA 及其强度、放大模型等）、输入图片（可从相册或拍照上传）。生成时顶部显示进度面板：正在执行的节点、步数进度条与百分比、后面排队的任务数。底部是大号“开始生成”、生成次数和停止按钮，上方显示实时预览和最新结果，点击可放大或播放视频。右上角“⋯ → 选择显示的参数”可自己挑选；选择保存在工作流文件里，与电脑端 ComfyUI 的 App 模式共用，保存工作流后在电脑和其他设备上也一样。下次打开 APP 会回到上次使用的模式。
- **AI 助手（ComfyUI-AgentLink）**：电脑装了 AgentLink 插件时，圆形菜单和简洁模式右上角有“AI 助手”，打开后直接用聊天让 AI 改提示词、调参数、运行当前画布。手机上聊天窗口占满屏幕（横屏也是），APP 的圆形按钮和进度标签会自动让开，返回键先关闭聊天；Android 10 上聊天时会暂时显示系统栏，保证输入法不挡住输入框。插件自带的✨悬浮按钮在手机上默认隐藏（可在“更多”中打开），APP 启动时不会自动弹出上次没关的聊天。手机第一次使用需在电脑的 AgentLink 设置里打开“手机访问”，再在手机的聊天窗口输入 6 位配对码；插件的新手机访问功能需要电脑上的 ComfyUI 完全重启一次才会加载。参考图可直接拍照上传。
- **提示词**：双击节点文字框（或只有一个文字框的提示词节点）进入原生全屏编辑页；单击只选择和拖动。字段名会标出【正向】/【反向】（根据实际连线判断）。多个文字框时让你选择，不猜。子图里的节点同样支持；被提升到子图节点上的文字框在外层编辑。
- **提示词工具**：“标签”把提示词按逗号显示成标签块，点一下即可调权重、左右移动或删除。权重 ± 作用于光标所在的词，不必精确选中。连续输入合并为一步撤销。模板附带的反向词可一键写入你选择的反向字段。
- **中英对照词库**：24 类、384 个英文词条、30 个完整英文模板，均有中文翻译，只插入英文。收藏、模板和历史保存在电脑的 `user/default/comfymobile/library.json`，手机与 iPad 自动同步（离线时先存本机，联网后合并）。
- **工作流**：圆形菜单“工作流”可保存到电脑、另存为、打开电脑上保存的工作流、新建、切换已打开的工作流；菜单顶部显示当前工作流名和是否未保存。电脑上的同一文件在你打开后被修改过时，保存前会提醒。
- **节点**：节点列表可搜索；可定位、编辑参数（下拉项可搜索，数值按节点规定的范围和整数要求检查）、只列出类型兼容端口的连线、断开、旁路、静音、复制、删除。删除等操作可用“撤销/重做”恢复。添加节点显示中文名和分类，不限数量。
- **任务**：显示运行中、排队、已完成和失败的任务，含时间、用时、缩略图、出错节点。可停止当前生成、取消排队、清空排队，查看任务全部结果，“换个种子再来一次”，把那次的工作流载入画布，或定位出错节点。生成时屏幕保持常亮（可在“更多”关闭）；切到后台时完成会发系统通知（首次需允许通知权限）。
- **结果继续改图**：看大图时点“设为输入图”，这张结果会直接填进工作流的“加载图像”节点（有多个时让你选），不用重新上传，适合 MOSS 等改图工作流反复迭代。
- **左右滑动看图**：从图库或任务打开的大图可左右滑动切换上一张、下一张（放大时不切换）；iPad 也可点 ‹ › 按钮。
- **参数预设**：简洁模式参数上方有一排预设，点一下即应用；“＋ 存为预设”把当前尺寸、步数、采样器、模型等存成一组（提示词和输入图片不放进去）。预设保存在工作流文件里，保存工作流后电脑、手机、iPad 都能用；节点被删改时对应项会跳过。
- **图库**：按需加载缩略图，滚动到底自动加载更多。看原图可双指或双击放大；支持视频播放与保存。可多选批量保存。“分享”不会在相册里多存一份。保存位置：图片在相册 `Pictures/ComfyMobile`，视频在 `Movies/ComfyMobile`，其他文件在 `Download/ComfyMobile`。
- **原版功能**：原版菜单里的导出、节点右键“保存图片”等下载会直接存到手机；上传图片时可以直接拍照。
- **稳定性**：手机内存不足导致编辑器网页进程被回收时，APP 自动重新载入而不是闪退。连不上电脑时显示重试卡片，网络恢复后自动重连。返回键先关闭原版的弹窗和菜单，在画布页需连按两次才退出。

草稿保存在本机；工作流需在“工作流”里保存到电脑。切换工作流、重新加载页面或删除目标节点后，需重新选择提示词字段。

## 范围与当前限制

- 完整画布由 WebView / Safari 加载电脑现有前端；手机端不安装模型，也不提供新的推理引擎。
- 特殊插件界面（姿态、蒙版、3D 等）使用插件原界面，触屏兼容性未验证。
- 服务器地址支持根路径 HTTP(S)，不支持带路径前缀的反向代理。
- 本地开发签名保存在 `.tools/comfymobile-dev.keystore`，请保留，后续升级需要同一签名。它不是商店发布签名。

## 构建与测试（Windows）

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup-tools.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

版本号只写在 `version.properties`。只运行自动测试：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1 -TestOnly
```

真实前端检查（只读代理，不提交生成、不改电脑上的工作流和设置）：

```powershell
node .\scripts\smoke-mobile-input.cjs
```

```powershell
node .\scripts\smoke-adapter.cjs
```

```powershell
node .\scripts\smoke-web.cjs
```

输出为 `output/ComfyMobile-0.4.4.apk`。本版验证记录见 `docs/v0.4.0-verification.md`。提示词插入、权重、标签和收藏合并规则由 `tests/prompt-cases.tsv` 与 `tests/merge-cases.tsv` 同时检查 Java 与网页两套实现。
